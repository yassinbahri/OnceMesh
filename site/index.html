Read the signal correctly

Observation is not endorsement.

The monitor makes one credential-free request to each active public endpoint. It publishes only a state, response code, and elapsed time. No payloads, identities, resolved addresses, or error details enter the snapshot.

Read the complete method →
Up
The protocol returned 200 or its expected unauthenticated 401.
Degraded
HTTPS answered, but not with the expected protocol response.
Down
The hosted monitor could not complete DNS, connection, TLS, or the request.
Not checked
The entry is suspended or retired, or no current observation exists.
