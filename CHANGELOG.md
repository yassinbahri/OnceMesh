# Changelog

All notable changes are recorded here. OnceMesh follows Semantic Versioning for
the Python package and explicit versioning for protocol objects.

## 0.1.0 — 2026-08-25

Initial public alpha release candidate.

- Immutable action, result, artifact, validation, receipt, and federation
  protocols with portable conformance vectors.
- Policy-controlled exact reuse, authorization partitions, signed receipts,
  revocation, conditional validation, and stale-while-revalidate.
- Authenticated TLS federation reference transport and operator handoff tooling.
- Native Python, LangGraph, LangChain, and LlamaIndex adapters.
- Memory, cross-process JSON, and SQLite/WAL active-key indexes.
- Cross-platform crash, contention, integrity, Node, and Docker evidence.
- Strict organization-pilot schemas and fail-closed aggregate evidence reporter.
- Cross-platform CI, CodeQL, dependency auditing, coverage, repository hygiene,
  trusted publishing, and clean-distribution verification.
- Architecture, trust-boundary, performance, test-duration, compute-saving, and
  economic-model documentation backed by machine-readable hosted evidence.
- Fixed conditional substitution reporting so the schema-shaped result is
  returned instead of falling through with no value.

This release is pre-production. Real organization proof of value and a genuinely
independent federation pilot remain external acceptance requirements.
