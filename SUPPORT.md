# Support

OnceMesh `0.x` is an alpha open-source protocol and reference implementation.
Community support is provided through public repository issues and discussions
on a best-effort basis; there is no response-time, availability, or data-recovery
service-level agreement.

Use the bug template for reproducible defects and the specification template for
new protocol behavior. Do not post private inputs, artifacts, credentials, or
signing seeds. Report vulnerabilities privately as described in `SECURITY.md`.

Before requesting help, include the OnceMesh version, Python and operating-system
versions, adapter versions, the smallest content-free reproduction, and the
relevant validation output. Production incident response remains the deploying
operator's responsibility.
