# 0025 — Release readiness does not imply production proof

Status: accepted

OnceMesh separates a reproducible open-source package release from claims about
organization value and independently operated federation. CI, synthetic pilot
fixtures, local TLS, and isolated containers can establish implementation
quality, but the project will not label them real operational evidence.

The `0.1.0` release therefore remains pre-production. M1 and M3 close only from
dated evidence and sign-off supplied by actual independent operators.
